一键诊断

生成一个文本文件（模块版本 · 运行状态 · BL 属性 · 三处日志尾部）到 Download 目录，直接发给开发者即可。不包含 keybox 内容与管理员令牌；应用列表只记录数量；日志中的设备标识（IMEI/序列号等）已自动脱敏。日志里可能含有包名，分享前请自查。

Debug 模式 检测中…

开启后，keybox 获取 / 指纹生成 / 身份同步 / 作用域维护 / 开机滴答会把每一步决策（下载尝试、哈希对比、身份变更、GMS 播种等）写入统一的 debug.log，排障不再靠猜。默认开启，模块稳定后可关闭。

读取中…

Keybox 获取 = keybox-fetch.log · 作用域同步 = apps-sync.log · 守护进程 = 引擎内存日志（admin socket） · Debug = debug.log（统一详细日志）
