选中的渠道优先抓取，失败自动回退其余渠道；自定义渠道见 keybox-sources.conf。"手动获取"按当前渠道强制抓取一次（会接管用户导入的 keybox 为自动管理，原文件保留备份），之后按刷新间隔自动续期。卸载模块会连同 /data/adb/teesim 一起删除（keybox.xml 与滚动备份都在其中）——需要保留请先把它拷出该目录。

Keybox 默认从社区源自动获取并定时刷新，主渠道失败时自动轮换备用渠道（Yurikey · KOWX712 镜像）。上方显示的是社区渠道对渠道最新 keybox 的报告，不是 Google 对本机 keybox 的实时判定；实际以 SPIC / Play Integrity API Checker 为准（检测应用需加入受保护列表）。导入自己的 keybox.xml 到 /data/adb/teesim/keybox.xml 后：自动刷新会让路不覆盖，且模块会在下一次检查时自动让引擎重读新箱（通常几分钟内生效，重启则立即生效）——不要为此点"手动获取"，那会从渠道重新抓取并接管你的导入。
